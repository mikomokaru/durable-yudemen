# 由来の印と採否の観測（2026-09-13）— **配備済み・採用 0 件を計数した**

官能評価を成立させるための前提。「画面に出ている提案がどちらの計画器のものか」を言えるようにする。

## 1. 入れたもの（実装済み・未配備）

### 1.1 `cpsat.plan-decided`（`StoreTimerDO.deliverPlan`）

外部計画の受領ごとに 1 行。`OBSERVE_DEBUG` に関係なく常に出す——採否は有効化判断の根拠であって、
debug のときだけ在ればよい値ではない。`emitSeam`（Instrumentation_Log の 4 継ぎ目限定・要件4.9）は
通さない。これはその 4 つに当たらない。

| 欄 | 意味 |
|---|---|
| `outcome` | **今回の受領**が採用されたか（`adopted` / `rejected`） |
| `standingAcceptedSlices` / `standingAcceptedPlacements` | **由来の印。** いま画面に出ている配置のうち外部計画由来の一片数・杯数 |
| `planner` / `requestId` / `inputKey` | 生値から読んだ申告。信じて何かを決めることはせず、記録に残すだけ |
| `arrivedSlices` / `arrivedPlacements` | 届いた計画の規模 |
| `storeId` | |

**2 欄を分けているのが要点である。** 全棄却は状態をそのまま返すので、以前の受領で採用した一片が
状態に残る。`standing` だけを見れば棄却を採用と読み、`outcome` だけを見れば画面の由来が言えない。

採否の判定は組み直していない——`receivePlan` の全棄却は「状態を変えず Effect も出さない」と
明示されているので、Effect 列が空かどうかがそのまま採否である（遷移後の `acceptedSlices` を
見ると上記の理由で誤る。実装の初版はそれを踏んだので直した）。

### 1.2 `cpsat-plan-computed` に `slices`（卓の数）

**棄却の段を集計で分けるために要る。** `admit` の内側の理由（段 1 の被覆／feasibility か、段 2 の
非改善か）を運ぶには engine の `Outcome` の契約を動かすことになる。代わりに次で分ける。

| 観測される組 | 読み |
|---|---|
| `pending > 6` かつ `slices == 1` かつ `rejected` | **段 1・卓の完全被覆**。計画の良し悪しではない |
| `pending ≤ 6` かつ `rejected` | **段 2・非改善**（被覆は満たしている） |
| `adopted` | 画面の当該卓は CP-SAT 由来 |

> スキーマ変更は今回加えない。**

## 5. 配備後の手順と、その見込み

1. 評価店舗で `pending` を 6 件以下に保つ（Start・Complete の操作だけで成立する）。
2. `cpsat.plan-decided` の `outcome` と `standingAcceptedSlices` を見る。

**ただし 7-B の実測は、これだけでは CP-SAT の提案が画面に出ない見込みを示している。**
`pending ≤ 6` の 3 局面（20 分窓・199 局面中）では被覆は満たされたが、合成後の総和は
6245→7040・7294→8972・5923→5923 で、いずれも改善していない。`admit` は真の改善だけを採る。
段 B 全体でも CP-SAT が engine の費用関数で下回ったのは 199 局面中 3 件である。

**それでもこの配備を先に行う価値は変わらない。** 「被覆で落ちた」のか「engine の費用で本当に
良くなかった」のかを分けられることが、次の手（R-1 の独立費用関数か、R-2 の合成先行か）を
決める唯一の材料だからである。段 2 の非改善が続くなら、問うべきは費用関数であって配線ではない。

### R-2 の第 3 案（合成を admit の前に動かす）

CP-SAT の先頭 6 件と engine の尾部を**1 つの一片にまとめてから**受理判定へ出す案は、
**`isStale` を緩めない**——合成後の一片は卓の対象を全件置くので完全被覆を満たす。
plan-stability の不変条件を守ったまま 7 件以上の局面でも CP-SAT の頭が残りうる。
3 案のうちこれを推す。ピークの提案を見たくなった時点で入れる。
