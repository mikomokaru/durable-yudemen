# 提案は店舗全体で最早の群だけを出し、時刻を見せず、入れてよい瞬間に現れる

> **（2026-09-05 改訂）** 表題の「最早の群だけ」は、翌日のレビューで `lift-group-display` 判断 19 が Visible_Groups（最早の群と、それより前の群がすべて Group_Started である群）へ広げた。同じレビューで押せるのは群の先頭だけになり（判断 17）、「始まった」の事実は snapshot から定義された（判断 16）。時刻を見せず、出現そのものを合図にする判断は変わらない。以下の本文は取り消し線と注記で改訂を示す。

釜ごとに「次の 1 件」を時刻付きで出す形（slot-suggested-start）は、放置すると全提案が `now` へ収束し、順序と間隔という計画の中身が画面から消えた。間隔を保って追随させる案（lapsed-suggestion-timing）も検討し実装したが、根本は「複数の提案を同時に時刻で描く」ことにあると判断し、次のように改める。

- ~~出すのは **店舗全体で最早の群** だけ（群の中で最も早い startAt 順）。~~ **（2026-09-05 改訂・判断 19）** 出すのは Visible_Groups——群を最早 `startAt` 順に G1, G2, … と並べ、G1 と、それより前の群がすべて Group_Started（判断 16）である Gk（`lift-group-display` AC 2.8）。最早の群だけでは「G1 は担当外だが G2 は担当内」の端末が空白になり、次の群の連鎖（AC 2.10）と衝突していた。群の全員を出す。担当外の端末は空白——判定は Visible_Groups の全品目で行う（AC 2.12）。端末同士の同期機構は要らない——全端末が同じ snapshot から ~~同じ最小を取る~~ 同じ集合を導く。
- 提案は **startAt の 60 秒前に薄く現れ（語なし）、startAt で濃くなり `now`** と描く。60 秒は麺を準備する猶予で、domain の定数。時刻（秒読み・壁時計・間隔）は一切描かない。
- ~~薄くても押せる（提案は指示ではない）。~~ **（2026-09-05 改訂・判断 17）** 押せるのは Group_Head（群の未着手のうち `startAt` 最小の品目・同値は全部）だけで、先頭は薄くても押せる。先頭でない品目は薄く見えるが丸ボタンを描かず、`startAt` が過ぎても濃くしない（AC 2.4・3.6）。群の中の順を違えると残りが錨に届かず群ごと遅れる（`lift-group-planning` 判断 5）ためで、提案は指示ではない、は変わらない。走行中・茹で上がりのカードには出さない。次の群は「現在の群の最初の 1 本が始まった」かつ「自身の 60 秒前が来た」で現れる。**（2026-09-05 改訂・判断 16）** 「始まった」は Group_Started——群の卓が非 null で、同じ卓の走行中（茹で上がりを含めない）`TimerFact` に `endTime` が群の `serveAt` に等しいものが在ること（AC 1.7・ワイヤに `TimerFact.orderItem` を足した、ADR-0003 改訂）。端末の履歴ではなく snapshot から決まり、走行中の仲間が茹で上がると後続の群は再び隠れる（Requirement 6.3 の例外）。群は可視化しない。
- 提案されていない品目を品目として始める口は、釜のラジアルに店舗全体の待ち行列（到着順）として足す。レールは事実の一覧のまま。

「計画は待てと言ってよい」と「時刻を出さない」を両立させる方法は、出現そのものを合図にする以外にない。時刻を出せば減らない秒読みか間隔の表示が要り、どちらも嘘か認知負荷を生む。

## Considered Options

- **釜ごとに次の 1 件**（現行）: 複数の時刻が並び、放置で収束する。
- **錨を現在へ繰り上げて間隔を保つ**（lapsed-suggestion-timing）: 正しいが、見せる情報が多い。担当外に錨がある端末で「+3:00」の基準が読めない。
- **担当範囲で最早の群**: 各端末に常に「自分の次」があるが、同じ計画が端末ごとに違う順で見える。店舗全体を選び、空白を受け入れた。

## Consequences

- `lapsed-suggestion-timing` は当初「マージしない」としたが #27 としてマージされていた（2026-09-04 に実測）。本 ADR の表示（lift-group-display）が `planAnchor` / `suggestionTiming` を撤去して置き換える。
- 現場が「次はどの釜か」を先読みする手段は画面から消える。全体の量感はレールが担う。
